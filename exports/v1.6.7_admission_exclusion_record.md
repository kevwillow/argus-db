# v1.6.7 Admission Exclusion Record (MAC-350)

Ships with the v1.6.7 export data. Records admission-level exclusions made
during the MAC-348 + MAC-349 combined APK promotion, per the CEO Gate-2 ruling
(MAC-350 comment `e8e9a63e`, 2026-06-12).

## 1. `258eafa5-e914-47da-95ca-c5ab0dc85b11` — DROPPED from board-ratified MAC-348

- **Was:** ratified in the MAC-348 +7 Gate-1 plan as a conf-70 SoundThinking
  `ble_service_uuid` ("device pairing; shared by both SoundThinking apps").
- **Finding:** static analysis (baksmali + dex grep) found the exact value as a
  literal string in **8 unrelated vendor APKs** — Axon (`com.axon.one`,
  `com.evidence`), Verizon Connect, Samsara, Fleetio, Motorola CommandCentral,
  Flock Safety — plus both SoundThinking apps. In Axon it is
  `const-string "258EAFA5-E914-47DA-95CA-C5AB0DC85B11"` in obfuscated util class
  `ov/i`. A value present across 8 unrelated vendors is a shared SDK/namespace
  constant, **non-discriminating**, and cannot serve as a single-vendor
  signature; promoting it would false-positive across all 8 vendors.
- **Disposition:** DROPPED. MAC-348 admits **+6**, not +7. Integrity correction,
  conservative direction, reversible (staged, not pushed). CEO owns the deviation
  from the board-ratified +7 and surfaces it to the board at the push gate;
  re-adding is a one-line change if overruled.
